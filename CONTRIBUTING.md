# Contributing to ClimbStack Website

Thank you for your interest in contributing to the ClimbStack landing page and website!

## Ways to Contribute

- **Reporting Issues**: Found a bug or broken link? Please open an issue on GitHub.
- **Design & Performance Improvements**: Propose ideas or optimizations via pull requests.
- **Translations (i18n)**: Help improve or add language dictionaries in `js/i18n/`.

## Local Development

The site is built with vanilla HTML5, CSS3, and modern JavaScript. No complex build step or packaging required:

```bash
# Serve locally
python3 -m http.server 8000
# Or using Node
npx serve .
```

## Pull Request Guidelines

1. Fork the repository and create your branch from `main`.
2. Ensure HTML adheres to W3C standards and passes accessibility checks.
3. Keep code and comments in English.
4. Verify that the site looks great on both mobile and desktop screen sizes.
