# Security Policy

## Reporting Security Issues

We take the security of ClimbStack and its infrastructure seriously. If you discover a security vulnerability, please report it responsibly.

### Contact

- **Email**: [gizano.dev@gmail.com](mailto:gizano.dev@gmail.com)
- **App Security Policy**: [github.com/ClimbStack/climbstack-app/security/policy](https://github.com/ClimbStack/climbstack-app/security/policy)

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and affected components.

We will acknowledge receipt within 48 hours and work on a fix promptly.
